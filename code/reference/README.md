# reference/ksic_rev11.csv

Korean Standard Industrial Classification, 11th revision: code, Korean title, English title, level.
Classification published by Statistics Korea; table taken from the CRAN package KSIC 1.0.2 (J. Yun, 2025, ksicDB, rows with ksic_C = C11),
https://cran.r-project.org/package=KSIC. Used by extract_release.py to give industry titles for `ksic_code`.
